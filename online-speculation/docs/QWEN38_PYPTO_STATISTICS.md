# 在线更新的全局梯度统计

一次 Adam 更新需要两次全局检查：更新前计算梯度范数与裁剪比例，更新后确认候选 FP32 参数有限。第二次检查通过后，才允许渲染和发布新 head。两次检查均保留。

原实现每次依次提交初始统计、三级归约和结果汇总，共五次同步运行时调用。合并实现把相同计算编排为一个 CHIP 入口，只提交一次；统计缓冲、64 行分级归约顺序和裁剪公式均不改变：

\[
 n=\sqrt{\sum_j g_j^2},\qquad c=\min\left(1,\frac{\tau}{n+10^{-6}}\right).
\]

其中 \(g_j\) 是 FP32 梯度，\(\tau\) 是裁剪上限。除元素有限性外，还检查归约后的范数，拦截有限输入平方后溢出的情况。结果仍仅回读 96 字节；候选状态、当前服务权重及原子发布规则不变。

`training_statistics.py` 生成直线调用图，复用 `make_stats`、`make_reduce` 和 `make_summary` 的 inline 版本。`SuffixOptimizerPrograms(..., fused_statistics=True)` 选择合并入口，未启用时保留原路径。

## 实机结果

真实 Qwen3.8-27B last-1/last-4 参数 flat 形状，在一张 A2 上分别对照。每种形状测试正常裁剪、全零、不裁剪、NaN、正负 Inf 和平方溢出，共 14 项，全部通过：每级统计及最终输出逐位相同，保护行为一致，正常输入的字节保持不变。

| 参数范围 | FP32 flat 元素数 | 逐次调用中位耗时 | 合并调用中位耗时 |
| --- | ---: | ---: | ---: |
| last-1 | 104,861,696 | 5.954 ms | 2.441 ms |
| last-4 | 454,946,816 | 11.270 ms | 7.025 ms |

每项预热四次，两个实现交错测量各 20 次。时间包含同步运行时调用，是组件测量，不代表纯 kernel 时间或在线全流增益。510 项 CPU 回归通过；真实 TP2 服务的连续更新、教师回放及发布权重逐位回归另行验收。

独立验证入口：`scripts/validate_qwen38_pypto_statistics.py`。原始结果、逐次计时、CPU 检查和启动信息见 `validation/pypto-qwen38/online-datasets-20261119/statistics214/`。设备进程正常退出，单卡已释放。
