# Orthrus-Qwen3.8-27B 验收摘要

日期：2026-10-31（北京时间；容器日志使用 UTC）。

**真实 27B 的推理、共享历史缓存、在线更新、head 保存重载及原生 API 链路已验证可运行；K32 的严格数值一致性仍有未通过项，不能宣称全部验收通过。**

## 范围

2 张 Ascend 910B3、BF16、TP2、K32、8K 总上下文，eager、同步、单请求执行；多个 HTTP 客户端可以排队。
Full Attention 块内双向，GDN 使用因果递推的混合层定义；外部 head 必须匹配这一约定及 `orthrus-qwen38-native-tp-v1` 格式。

## 未通过与边界

K32 的 JSON 请求在第二个 token 分叉，最终服务接口中也复现。无投机前两名目标 logits 为 16.625、16.5，32 行验证出现三个 16.625 的并列值。
固定相同输入和真实主模型权重，原生 linear 也能复现 batch 形状相关的输出变化；这是一个明确来源，尚未逐层归因所有最终 logit 误差。
映射 AR 视图对照的最大 TV=0.091089，高于预设 0.05 门槛，该数值对照同样未登记为通过。

当前不覆盖图模式、动态批处理、量化、PP/DP、多模态、长时间稳定性和生产 goodput。
本轮未开发新 NPU kernel；draft 使用现有 Torch/Transformers 组合，不据功能通过宣称已达到最优算子性能。
混合 batch 的零候选 RNG、`logprob_token_ids` 等镜像原生接口边界另记在详细记录中。
主动停服退出码为 0，但原生异步输出任务和 resource tracker 仍有关闭期错误/警告，不将停服日志描述为零报错。

本轮 head 来自 AR 参数复制初始化及少量功能更新，数据为功能测试提示；尚未拿到正式离线训练的 head，未证明业务接受率或吞吐提升。
本次服务和专用容器已停止，实查 167 的 0、4 卡没有运行进程；保留最终 head 和验证记录，不继续占卡。
