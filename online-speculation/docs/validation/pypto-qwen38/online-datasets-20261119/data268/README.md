# Pseudo2code 题池长度盘点

使用 LongProc 固定提交 `673ec4c230876e941d674116d66d28783c186b15` 的官方 Pseudo2code 0.5k 与 2k 文件，按当前 tokenizer、模板与输出预算计算长度；2k 是原始输出长度分组，不是上下文配置。来源 URL、Git blob 和 SHA256 保存在报告内。

在 512 总上下文、128 输出预算下，登记过的 130 个问题 ID 排除后，没有剩余问题。提高到 1,024 总上下文时，官方两个文件合计有 63 个尚未出现在该登记表中的合格问题；256 输出预算对应 61 个。完整计数见 `fresh268-official2k-lengths.json`。

这只是 CPU 长度审计，未运行推理、训练或挑选答案，也没有分配新确认题。“未出现在登记表”尚不等于可认证的新题：后续仍须核对三台机器实际启动请求、留出题和 head 训练来源。已消费的 24 题确认不再用于调参后的新题验收。扩展上下文也须先验证计算与服务链路，不能仅修改长度参数就宣称支持。
