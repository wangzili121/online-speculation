# SPoC 补充请求流

此处使用 [SPoC 作者发布的数据](https://github.com/sumith1896/spoc)，准备更长的伪代码到 C++ 请求流。SPoC 是 LongProc 此任务的来源之一，但本流不冒充原 LongProc 固定题集的结果。[SPoC 论文](https://proceedings.neurips.cc/paper/2019/file/7298332f04ac004a0ca44cc69ecf6f6b-Paper.pdf)说明了其数据构建和问题划分。

只使用官方 `train/spoc-train.tsv` 中的人类伪代码 `text` 和缩进，忽略答案 `code`，沿用 LongProc 的任务模板。排除全部 194 个 LongProc 问题 ID 及三台机器已执行文本后，在 1,024 总上下文、192 输出预算下，有 364 个问题可选。按原始顺序为每个问题取首个合格标注，固定分为 64 题探索、256 题新确认、32 题独立留出，三个集合的问题 ID 互不相交，余下 12 个未分配。

下载地址、压缩包与 TSV 的哈希、长度计数和选择清单均保留；没有根据答案、生成结果或速度筛题。当前未执行推理或训练。只有探索完整达标、配方冻结后，才使用确认题；吞吐验证不作为该数据集的代码正确率结论。
