# 三卡独立学习器辅助对照

使用三个物理 A2：两张运行 TP2 target / draft，第三张独立更新 last-1；AR 和固定起草阶段也保留相同三卡资源。后台更新的完整生成、反馈、训练、发布和流末尾等待分别记录。它属于三卡辅助实验，不用于两卡主验收，也不把不同卡数的吞吐放在一起充当在线增益。

原 C 机队列等待五小时仍未启动模型。迁移前核对 UID、完整命令、模型报告和日志，以及子进程；短暂暂停本任务的等待程序后再检查，仅允许空卡查询进程，确认无模型启动后停止这两个等待 PID。未停止其他用户或已在计算的任务，证明保存在 `C-stopped-waiting-only.json`。

B 机使用同一 source233 模型和 benchmark、同一 native 源码、逐字节核对的 step128 / step135 权重、原请求和配置。只调整物理主机、路径与空闲设备候选，仍由原空卡检查器取卡。先运行六条旧题的更新 / replay / 导出诊断，通过后再执行原 Pseudo2code 54 题和 GSM8K 384 题探索；新增一道完整 54 题正确性前置检查，避免故障后继续下一流。没有派发新预留题。

三组采用分别连续测量的 AR、固定、在线阶段，可能受时间漂移影响；与主实验逐请求交错计时区分。完整辅助结果不作三次新题确认的替代。

`source233_bundle.json.gz` 保存原实现及资产的只读 JSON 快照，不含模型权重；用 `gzip -dc source233_bundle.json.gz` 查看，`bundle-manifest.json` 保存其 SHA256 和逐文件绑定。当前主线模型代码可在仓库正常阅读，快照用于重现该辅助队列的限定版本。
