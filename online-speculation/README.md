# 共享骨干的并行起草与在线续训

主线保留双向注意力并行起草、精确 AR 校正、整块张量采样，以及基于预训练起草参数的在线注意力续训。

两条计算路径共享词嵌入、前馈网络、输出头和真实历史 KV。起草路径使用独立注意力投影，
一次处理“锚点 + 掩码块”；AR 路径验证候选，并提交通过的连续前缀。
在线版本重用有效验证行，保存冻结前段的表示，仅重放并更新起草注意力后段。
当前保留的在线配置采用完整词表 TV 监督，使学习直接对应实际采样分布的重叠质量。

冷启动分支从 AR 注意力副本开始，以实际交付的回答学习全部起草注意力。
短块训练与离线蒸馏共用更新核，平均时间预算控制训练及验证成本，候选通过速度门控后投入服务。
入口、恢复方式和同预算离线对照见 [运行说明](docs/RUNNING.md#冷启动的预算式完整块训练)。

固定起草、张量执行与 TV 在线续训各有配对加速证据，
具体条件、增量收益与更新成本集中记录在性能文档中。此前的低秩起草、半自回归小头、
概率混合及相关说明与测试集中在 [ablation/](ablation/README.md)。

## 主线结构

~~~text
src/blockspec/
  parallel/
    backbone.py        双视图层、真实 AR 历史、完整块后段重放
    branches.py        锚点与掩码块、候选行对齐
    generation.py      预填充、起草、验证、提交与缓存裁剪
    sampling.py        候选抽样与验证接口
    feedback.py        有效教师反馈与更新生命周期
    training.py        随机锚点、多块信息隔离、完整分布蒸馏
    fitting.py         数据流、梯度累积、调度与训练恢复
    online.py          FP32 主权重、起草注意力后段续训
    audit.py           同前缀分布与重放审计
    weights.py         配置驱动的张量映射与检查点
  sampling.py          概率变换、接受与正残差
  sampling_execution.py 整块张量校正、指数竞争、可选 GPU 图
  state.py / feedback.py 历史缓存与反馈数据结构
  losses.py            完整分布损失
  measurement.py       配对吞吐统计与状态一致性
  data.py / corpus.py / tokenizer.py 数据与分词
  reference.py / reporting.py 外部参照检查与公开报告
  commands/            固定评测、在线对照、离线训练入口
tests/                 主线数学、缓存、梯度、执行和恢复验证
ablation/              独立安装、独立测试的对照实现
~~~

`scripts/` 中的三个文件是已安装命令的简短入口。默认安装仅发现 `src/` 中的主线软件包，
默认测试仅运行 `tests/`。消融包单向复用主线的缓存、采样校正和通用工具。

## 后续拓展

已有起点的续训继续关注采样分布的重叠质量，以及反馈、反向和更新的总成本。
冷启动探索从 AR 注意力复制初始化，以已交付的完整序列更新全部起草注意力，
与离线入口共用完整块 KL 更新核；平均时间预算与验证发布控制服务成本。
每项变化分别记录学习后的静态质量和计入学习成本的在线吞吐。
主线以可复现的净吞吐收益选择实现；其他设计的代码与取舍归入 `ablation/`。

算法推导随实现更新，具体结果集中维护一份性能记录。
个人配置和实验产物保存在已忽略的 `local/` 或仓库外。
公开报告保留方法设置、指标和校验结论。每次提交前汇报性能与测试结果。
